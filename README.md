# クルナビ — ホロクル買い回りナビ

ホロクル（ホロライブオンリー即売会）用の **自分専用** 購入計画＆当日ナビ。
PCで計画を作り、スマホで会場を回りながら使います。データはすべて端末のブラウザ内だけに保存されます（サーバー不要）。

## できること

| 画面 | 内容 |
|---|---|
| **当日** | 次に行くサークルを大きく表示。アイテムをタップで「買った」、`全部買えた → 次へ` で自動的に次の目的地へ。売り切れ／あとで／見送り。追加購入・サークル外の支出をテンキーで記録。残り予算・見込み残・財布の現金を常時表示。**現在時刻（秒まで）と開場からの経過時間**、**この近くのまだ回っていないサークル**、**その場でメモ** も出ます |
| **いくら必要か** | リストタブの試算表。「必須だけ／優先まで／通常まで／全部」で合計・予算の残り・現金の残りを並べて比較できます。予算内で回れるところに色が付きます。当日タブの「この先いくら必要か」からも飛べます |
| **リスト** | 巡回順の一覧。ドラッグで並べ替え、優先度の変更。**ルート作成**（必須→残り／優先度順／最短）で配置図から回る順番を自動計算 |
| **配置図エディタ** | 設定から開くと、公式の配置図画像を取り込んで、その上に島・1列の机・壁サークル・**入口**・通り抜けできる通路を置けます。上部に「席が無いサークル ◯件」が出るので、0件になれば全サークルが配置図に載っています。13th 以降の会場もこれで作れます |
| **進行表** | 当日タブの「進行」で公式タイムテーブル（12:00 開始／13:00 当日カタログ組の入場・現金販売／16:00 終了）と、いまどの時間帯かを確認できます。列形成が始まったころ（9:50 前後）の目安も入れてあります |
| **マップ** | 配置図に計画中サークルを色分け（必須・優先・通常・余裕・済）、巡回番号とルート線を表示。ピンチ／ホイールで拡大、タップでサークル情報。**公式配置図の上に重ねる表示**にも切替可。スマホ縦持ちでは自動で縦向き表示 |
| **お品書き** | サークル詳細から **お品書きの写真を添付** できます（スマホならカメラでそのまま撮影）。当日画面のサークルにサムネイルが出るので、タップで拡大。画像は端末内（オフラインでもOK）|
| **サークル** | 全サークル検索（名前・スペース `G23`・`@ID`・メモ・品名／ひらがなカタカナ・全角半角を区別しない）。ブロック・計画中・お気に入り・前回購入で絞り込み。`＋` で即追加 |
| **設定** | 予算・別枠・持参現金、スタート地点、テーマ（ライト／ダーク）、文字サイズ、画面を消さない、データの送受信・バックアップ、購入記録・CSV出力、新しいイベントの作成 |

そのほか

- すべての操作に **元に戻す**（トーストのボタン / PCは `Ctrl+Z`）
- PCで作った計画は **QRコード** でスマホへ渡せます（設定 → 共有リンク）
- **巡回表の印刷**（設定 → 巡回表を印刷）。電池切れ・電波なしの保険に、順番・スペース・買うもの・チェック欄つきの紙を1枚
- 当日タブに現在時刻（秒まで）・開始からの経過・終了までの残り・未訪問1件あたりの持ち時間が出ます。自分の入場時刻は設定 → イベント → 開始（入場）で変えられます（12th は 12:00〜16:00 を最初から入れてあります）
- **次回以降のイベントで使い回せる**：「新しいイベントを作る」で公式サイトのサークル一覧を貼るだけ。お気に入り（♥）と過去の購入額は次のイベントでもサークル一覧に表示されます
- 価格未定のアイテムは、買った時にテンキーで金額を入れれば OK
- **買うものの入力が速くなる工夫**：一度入れた金額を覚えていて「＋新刊 ¥1,000」のようにチップに出ます（押すと金額ごと入ります）。同じ品名をもう一度押すと数量が増えます。「まとめて入力」に `新刊 1000` `アクスタ 1500 x2` のように並べて貼ることもできます。スマホでは価格欄をタップするとアプリのテンキーが出ます
- サークル一覧の **＋ を長押し**（PCは右クリック）すると、優先度を選んで追加できます
- お品書きの写真は **共有リンク・バックアップには含まれません**（容量が大きいため）。スマホで使う端末で撮り直すのがおすすめ。枚数と容量は「設定 → お品書きの画像」で確認・一括削除できます
- PC：`/` で検索、`Esc` で閉じる。サークル詳細は右パネルに開くので、一覧を見ながら編集できます

## 使い方の流れ

1. **PC**で `index.html` を開く（ダブルクリックでOK）
2. 「サークル」タブで欲しいサークルの `＋` → 詳細で優先度・買うもの・価格・メモを入力
3. 「設定」で予算を入れる → 「リスト」の **ルート作成**
4. 「設定 → スマホへ送る」で計画をスマホに移す（下記）
5. 当日はスマホで「当日」タブを見ながら回る

## スマホで使うには

スマホで使うには、アプリをどこかに置いて **https のURL** で開く必要があります。一度開けばオフラインでも動きます（会場の電波が悪くても大丈夫）。

### おすすめ：GitHub Pages（無料）

1. GitHub に新しいリポジトリを作り、このフォルダの中身をすべてアップロード
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 表示された `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開く
4. 共有メニューの「ホーム画面に追加」でアプリのように使えます

> 他に Netlify Drop（フォルダをドラッグ＆ドロップするだけ）や Cloudflare Pages でも可。

### 計画をPCからスマホへ送る

- **QRコード**（いちばん手軽）：PC（公開URLで開いたもの）の「設定 → 共有リンクをコピー」を押すと **QRコードが出ます**。スマホのカメラで読むだけで、計画がそのまま開きます
- **共有リンク**：同じ画面の「リンクを直接コピーする」→ LINE の自分用トーク等に送る → スマホで開くと読み込み確認が出ます
  - ※ QRに載せるため共有用データは軽量化してあります（計画・予算・お気に入りの♥は移ります。当日の購入記録まで丸ごと移したいときは下の「ファイル」で）
  - ※ 計画が100サークル前後を超えるとQRには入りきらないので、リンクかファイルで送ってください
- **ファイル**：「計画をファイルに書き出し」→ スマホへ送る → スマホの「ファイルから読み込み」

※ PCでファイルを直接開いている（`file://`）と、そのPC内のデータは公開URL側と別扱いになります。PCでも公開URLで作業するのが一番ラクです。

## PCとスマホで同期する（任意）

同じURLで開いても、入力した内容は**端末ごと**に保存されます。行き来させる方法は2つあります。

1. **手で渡す**（設定が不要）… PCで「共有リンクをコピー」→ QRをスマホで読む。帰宅後は逆向きに送れば購入記録もそのまま戻ります
2. **自動で同期する**… Google Apps Script に自分用の保管場所を作ると、変更が数秒後に自動で送られ、もう一方の端末で取り込めます

### 自動同期の準備（無料・10分）

1. [script.google.com](https://script.google.com/) で「新しいプロジェクト」
2. `tools/gas/コード.gs` の中身を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（合言葉が鍵になります）
4. 出てきた `.../exec` のURLをコピー
5. クルナビの **設定 → PCとスマホで同期 →「同期を設定する」** にURLと合言葉を入れる
6. スマホ側は **「設定をスマホへ（QR）」** のQRを読むだけで同じ設定になります

- 送られるのは計画・購入記録・お気に入り・自作の配置図です。テーマなどの画面設定とお品書きの写真は端末ごとに残ります
- 両方の端末で別々に変更したときは「どちらを残すか」を聞かれます（片方だけが残ります）
- 圏外のときは送らずに溜めておき、電波が戻ったら自動で送ります
- **端末を持ち替えたとき**（アプリに戻ってきたとき）に自動で最新を取り込みます。取り込んだときは「別の端末の変更を取り込みました」と出ます
- **同時編集はできません**。PCとスマホを交互に使う前提です（同時に編集すると、どちらを残すか選ぶことになります）

## オフラインでも使えます

一度 https のURLで開いておけば、会場で電波が切れてもそのまま使えます（計画・購入記録・地図・お品書き画像）。圏外のあいだは画面右上に「オフライン」と出て、X や pixiv のリンクだけが開けなくなります。

当日の朝、電波のあるうちに **設定 → オフライン → 「オフライン用に取り込み直す」** を一度押しておくと確実です。

## 注意

- データはブラウザ内（localStorage）保存です。ブラウザの履歴・サイトデータを消すと消えます。**当日前に「全データのバックアップ」を書き出しておく**のがおすすめ
- 配置図は公式PDF（`hall_holo12_配置図.pdf`）から作り直したもので、**600席すべての位置が公式図と一致**しています。ただし公式図は「調整中の内容を含む」ため、当日の変更には注意
- 12th のサークル一覧は貼り付けられた範囲（Q38 まで）を収録しています。足りないサークルは「サークル → 一覧にないサークルを手動追加」で追加できます
